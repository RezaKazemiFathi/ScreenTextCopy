# نصب ScreenTextCopy

[English](INSTALL.md) · **فارسی**

<div dir="rtl" align="right">

این صفحه دانلود، نصب، بررسی صحت فایل، ارتقا و حذف ScreenTextCopy 2.0.0 روی ویندوز را پوشش می‌دهد.

## پیش‌نیازها

| | |
|---|---|
| سیستم‌عامل | Windows 10 (نسخه 1809 یا جدیدتر) یا Windows 11 |
| معماری | فقط x64 |
| پیش‌نیازها | **هیچ** |
| دسترسی Administrator | لازم نیست |

واقعاً لازم نیست چیزی را از قبل نصب کنید. رانتایم .NET 8 داخل خود بیلد قرار دارد
(انتشار self-contained) و موتور OCR یعنی Tesseract 5 به‌همراه داده‌های زبانی
انگلیسی، فارسی و عربی درون بسته قرار گرفته است. نه نصب .NET، نه نصب Tesseract و نه
Visual C++ redistributable.

## کدام فایل را دانلود کنم؟

هر دو در [صفحه آخرین انتشار](https://github.com/rezakazemifathi/ScreenTextCopy/releases/latest) موجود هستند.

| فایل | چه زمانی مناسب است |
|---|---|
| `ScreenTextCopy-Setup-<version>-win-x64.exe` | میان‌بر Start Menu و دسکتاپ می‌خواهید، ورودی برنامه در *Installed apps* باشد و ارتقا روی نسخه قبلی انجام شود. گزینه پیشنهادی. |
| `ScreenTextCopy-<version>-win-x64-portable.zip` | نمی‌توانید یا نمی‌خواهید چیزی نصب کنید، یا می‌خواهید برنامه را از حافظه USB اجرا کنید. |
| `SHA256SUMS.txt` | همیشه — با آن می‌توانید صحت هر فایلی که دانلود کرده‌اید را بررسی کنید. |

## گزینه A — نصب با installer

1. فایل `ScreenTextCopy-Setup-<version>-win-x64.exe` را دانلود کنید.
2. اجرایش کنید. اگر Windows SmartScreen ظاهر شد، بخش [SmartScreen](#smartscreen-و-پیام-ناشر-ناشناس) در ادامه را بخوانید.
3. مجوز استفاده را بپذیرید و مراحل ویزارد را طی کنید.
4. گزینه‌های دلخواه را انتخاب کنید:

   | گزینه | پیش‌فرض |
   |---|---|
   | ساخت میان‌بر روی دسکتاپ | فعال |
   | اجرای خودکار ScreenTextCopy هنگام بالا آمدن ویندوز | غیرفعال |
   | اجرای ScreenTextCopy پس از پایان نصب | در صفحه آخر پیشنهاد می‌شود |

   ورودی Start Menu و برنامه حذف (uninstaller) همیشه ساخته می‌شوند.
5. پایان. برای اولین ثبت متن `Ctrl + Shift + X` را بزنید.

### محل نصب، و اینکه چرا پیام UAC نمی‌بینید

نصب‌کننده **برای همان کاربر** (per-user) است و در این مسیر می‌نویسد:

```text
%LocalAppData%\Programs\ScreenTextCopy
```

این یک تصمیم عمدی در طراحی است، نه میان‌بُر. برنامه بسته‌های زبانی OCR را که
درخواستی دانلود می‌کنید، کنار فایل اجرایی خودش در `<app>\Tesseract\tessdata`
نگه می‌دارد. داخل `Program Files` این پوشه برای یک پروسه عادی فقط-خواندنی است،
پس نصب یک زبان جدید از تنظیمات با خطای access-denied شکست می‌خورد، مگر آنکه کل
برنامه با دسترسی بالا اجرا شود. مسیر per-user این پوشه را قابل نوشتن نگه می‌دارد
و باعث می‌شود هیچ‌وقت به رمز Administrator نیاز نباشد.

## گزینه B — نسخه portable

1. فایل `ScreenTextCopy-<version>-win-x64-portable.zip` را دانلود کنید.
2. آن را هرجا که دوست دارید استخراج کنید، از جمله روی یک حافظه USB.
3. `ScreenTextCopy.exe` را اجرا کنید.

تنظیمات شما همچنان در `%AppData%\ScreenTextCopy` روی همان دستگاهی که برنامه را
اجرا می‌کنید ذخیره می‌شود، پس نسخه portable پیکربندی‌اش را بین کامپیوترها جابه‌جا
نمی‌کند.

## SmartScreen و پیام «ناشر ناشناس»

بیلد منتشرشده **code-signed نیست**، بنابراین ویندوز ممکن است پیام
*«Windows protected your PC»* را نشان دهد یا هشدار بدهد که ناشر ناشناس است. این
رفتار برای یک بیلد امضانشده طبیعی است و حرفی درباره محتوای فایل نمی‌زند.

برای ادامه: روی **More info** و بعد **Run anyway** کلیک کنید.

بررسی واقعی سلامت فایل با checksum انجام می‌شود. هش فایل دانلودی را با خط متناظرش
در `SHA256SUMS.txt` مقایسه کنید:

```powershell
Get-FileHash .\ScreenTextCopy-Setup-2.0.0-win-x64.exe -Algorithm SHA256
```

اگر هش یکسان بود، فایل بایت‌به‌بایت همان چیزی است که منتشر شده. اگر یکسان نبود،
پاکش کنید و دوباره دانلود کنید.

## ارتقا

1. نصب‌کننده نسخه جدیدتر را دانلود کنید.
2. آن را روی نصب فعلی اجرا کنید.

نصب‌کننده از یک AppId ثابت استفاده می‌کند، پس نسخه جدید جای نسخه قبلی را می‌گیرد و
کنار آن نصب نمی‌شود؛ اگر برنامه در حال اجرا باشد هم پیش از جایگزینی فایل‌ها به‌طور
خودکار بسته می‌شود. تنظیمات، API key و بسته‌های زبانی دانلودشده دست‌نخورده
باقی می‌مانند.

## حذف برنامه

1. در ویندوز به **Settings → Apps → Installed apps** بروید.
2. **ScreenTextCopy** را پیدا کنید و **Uninstall** را بزنید.
3. برنامه حذف از شما می‌پرسد که آیا `%AppData%\ScreenTextCopy` هم پاک شود یا نه —
   یعنی تنظیمات، API key ذخیره‌شده و بسته‌های زبانی OCR دانلودشده. پاسخ پیش‌فرض
   **No** است که آن‌ها را برای نصب بعدی نگه می‌دارد. فقط اگر می‌خواهید کاملاً پاک
   شوند **Yes** را انتخاب کنید.

برای نسخه portable، پوشه‌ای که استخراج کرده‌اید را پاک کنید؛ اگر می‌خواهید تنظیمات
هم بروند، `%AppData%\ScreenTextCopy` را هم حذف کنید.

## فایل‌ها و پوشه‌ها

| مسیر | محتوا |
|---|---|
| `%LocalAppData%\Programs\ScreenTextCopy` | خود برنامه (فقط در حالت نصب با installer) |
| `<app>\Tesseract\tessdata` | بسته‌های زبانی OCR، هم همراه برنامه و هم دانلودشده |
| `%AppData%\ScreenTextCopy\settings.json` | همه تنظیمات، از جمله API key شما |

حذف `settings.json` همه چیز را به حالت پیش‌فرض برمی‌گرداند؛ برنامه در اجرای بعدی
دوباره آن را می‌سازد.
